# Установка через HACS

HACS (Home Assistant Community Store) позволяет легко устанавливать кастомные интеграции.

## Предварительные требования

1. **HACS должен быть установлен** в вашем Home Assistant
   - Если HACS не установлен: https://hacs.xyz/docs/setup/download

2. **Репозиторий должен быть в Git** (GitHub, GitLab, Gitea или Bitbucket)

## Способ 1: Добавление как Custom Repository (рекомендуется)

### Шаг 1: Загрузите интеграцию в Git репозиторий

Если у вас ещё нет репозитория:

1. Создайте репозиторий на GitHub/GitLab (например: `ha-smm-9000`)
2. Загрузите код:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/ваш-username/ha-smm-9000.git
   git push -u origin main
   ```

### Шаг 2: Добавьте репозиторий в HACS

1. В Home Assistant перейдите в **HACS**
2. Перейдите в раздел **Интеграции**
3. Нажмите на три точки (⋮) в правом верхнем углу
4. Выберите **Custom repositories**
5. Введите:
   - **Repository**: `https://github.com/ваш-username/ha-smm-9000` (URL вашего репозитория)
   - **Category**: выберите **Integration**
6. Нажмите **Add**

### Шаг 3: Установите интеграцию

1. После добавления репозитория интеграция появится в HACS
2. Найдите **Grand Meyer SMM-9000** в списке интеграций
3. Нажмите на интеграцию
4. Нажмите **Download** (Скачать)
5. Перезапустите Home Assistant

### Шаг 4: Добавьте интеграцию в Home Assistant

1. Перейдите в **Настройки → Устройства и сервисы → Добавить интеграцию**
2. Найдите **Grand Meyer SMM-9000**
3. Введите параметры:
   - IP адрес устройства
   - Пароль
4. Готово!

## Способ 2: Добавление в HACS как default repository (для публикации)

Если вы хотите, чтобы интеграция была доступна всем пользователям HACS:

1. Репозиторий должен соответствовать требованиям HACS:
   - Правильная структура файлов
   - Valid `manifest.json`
   - README.md с описанием
   - Документация

2. Подайте заявку на добавление в HACS Default:
   - https://github.com/hacs/default/issues
   - Создайте issue с запросом на добавление

## Важные замечания

### Структура репозитория для HACS

HACS ожидает следующую структуру:

```
ha-smm-9000/
├── custom_components/
│   └── smm_9000/
│       ├── __init__.py
│       ├── manifest.json
│       └── ... (остальные файлы)
├── README.md
└── ...
```

### Требования к manifest.json

Ваш `manifest.json` уже правильный, но убедитесь что:

```json
{
  "domain": "smm_9000",
  "name": "Grand Meyer SMM-9000",
  "version": "1.0.0",
  "requirements": ["websockets>=11.0"],
  ...
}
```

### Версионирование для обновлений через HACS

HACS отслеживает обновления через:
- Git tags (рекомендуется): `v1.0.0`, `v1.0.1`, и т.д.
- Или файл `hacs.json` с полем `version`

Для создания тега:
```bash
git tag v1.0.0
git push origin v1.0.0
```

## Преимущества установки через HACS

✅ **Автоматические обновления** - HACS покажет уведомление о новых версиях
✅ **Простая установка** - один клик для установки и обновления
✅ **Управление версиями** - легко откатиться на предыдущую версию
✅ **Интеграция в UI** - интеграция появляется в стандартном интерфейсе HACS

## Если репозиторий приватный

HACS поддерживает приватные репозитории только для GitHub и только если:
- Вы используете GitHub Personal Access Token
- Токен добавлен в настройки HACS

Для публичных репозиториев токен не нужен.
