# Исправление ошибки версии в HACS

## Проблема

HACS показывает ошибку:
```
The version a86d707 for this integration can not be used with HACS.
```

## Решение

HACS определяет версию из **Git tags**. Тег `v1.0.0` уже создан локально, теперь нужно загрузить его в GitHub.

### Шаг 1: Загрузите тег в GitHub

```bash
# Загрузите тег в удаленный репозиторий
git push origin v1.0.0

# Или загрузите все теги сразу
git push --tags
```

### Шаг 2: Проверьте на GitHub

Убедитесь, что тег появился на GitHub:
- Откройте `https://github.com/ваш-username/ha-smm-9000/tags`
- Должен быть виден тег `v1.0.0`

### Шаг 3: Обновите в HACS

1. В HACS перейдите в **Интеграции**
2. Найдите **Grand Meyer SMM-9000**
3. Если есть кнопка **Перезагрузить** - нажмите её
4. Или удалите репозиторий из Custom repositories и добавьте заново

### Шаг 4: Проверьте версию

После загрузки тега HACS должен показывать версию **1.0.0** вместо hash коммита `a86d707`.

## Для будущих обновлений

При каждом новом релизе создавайте новый тег:

```bash
# Обновите версию в manifest.json (например, на 1.0.1)
# Затем создайте и загрузите новый тег:
git add custom_components/smm_9000/manifest.json
git commit -m "Bump version to 1.0.1"
git tag v1.0.1
git push origin v1.0.1
```

## Проверка версии в manifest.json

Убедитесь, что версия в `manifest.json` совпадает с тегом (без префикса `v`):

- Тег: `v1.0.0`
- В manifest.json: `"version": "1.0.0"`

Текущая версия в manifest.json: ✅ `1.0.0` (правильно)
