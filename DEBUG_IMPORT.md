# Отладка ошибки импорта config_flow

## Ошибка
```
Exception importing custom_components.smm_9000.config_flow
```

## Возможные причины

1. **Библиотека websockets не установлена** - Home Assistant должен установить её автоматически, но иногда требуется перезагрузка
2. **Циклические импорты** - возможно проблема в импортах между модулями
3. **Синтаксические ошибки** - хотя py_compile прошёл успешно

## Что проверить в логах

Посмотрите полный traceback ошибки в логах Home Assistant. Обычно там есть более детальная информация:

1. **Настройки → Система → Логи**
2. Найдите полный traceback ошибки
3. Ищите строки типа:
   - `ModuleNotFoundError: No module named 'websockets'`
   - `ImportError: cannot import name ...`
   - Другие детали ошибки

## Решения

### 1. Убедитесь, что зависимости установлены

Проверьте, установлена ли библиотека websockets:

В логах Home Assistant должны быть строки о установке зависимостей, если websockets не установлена.

### 2. Перезагрузите Home Assistant

После установки файлов обязательно перезагрузите Home Assistant полностью.

### 3. Проверьте версию Home Assistant

Интеграция требует Home Assistant 2023.1.0 или новее. Проверьте версию в **Настройки → Система → Информация**.

### 4. Проверьте структуру файлов

Убедитесь, что все файлы на месте и имеют правильные права доступа.

### 5. Временно упростите config_flow для теста

Если проблема продолжается, можно временно упростить validate_input, чтобы проверить, в чём именно проблема.

## Что нужно от пользователя

Пожалуйста, пришлите полный traceback ошибки из логов Home Assistant. Там должна быть более детальная информация о том, что именно не работает при импорте.
