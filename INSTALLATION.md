# Инструкция по установке интеграции SMM-9000 в Home Assistant

## Способ 1: Установка через файловую систему (рекомендуется)

### Шаг 1: Определите путь к директории Home Assistant

Путь зависит от типа установки Home Assistant:

- **Home Assistant OS** (Supervisor): `/config/custom_components/`
- **Home Assistant Container** (Docker): `/config/custom_components/` (внутри контейнера)
- **Home Assistant Core** (Python venv): `~/.homeassistant/custom_components/` или путь из `configuration.yaml`
- **Home Assistant Supervised**: `/usr/share/hassio/homeassistant/custom_components/`

### Шаг 2: Скопируйте интеграцию

#### Вариант A: Если у вас есть SSH доступ

```bash
# Подключитесь к устройству с Home Assistant
ssh root@your-ha-ip

# Перейдите в директорию custom_components
cd /config/custom_components/

# Скопируйте папку интеграции
# Если вы используете git или имеете доступ к файлам
# Пример через scp (выполните на вашем компьютере):
```

С вашего компьютера (где находится проект):

```bash
# Замените your-ha-ip на IP адрес вашего Home Assistant
scp -r custom_components/smm_9000 root@your-ha-ip:/config/custom_components/
```

#### Вариант B: Через Samba (Windows Network)

1. Убедитесь, что в Home Assistant включен **Samba add-on**
2. Откройте сетевые диски в Windows: `\\homeassistant\config`
3. Перейдите в папку `custom_components`
4. Скопируйте папку `smm_9000` из проекта в эту директорию

#### Вариант C: Через File Editor add-on

1. Установите **File editor** add-on в Home Assistant (если еще не установлен)
2. Откройте File editor
3. Создайте папку `custom_components` если её нет
4. Создайте папку `smm_9000` внутри `custom_components`
5. Скопируйте все файлы из `custom_components/smm_9000/` проекта в эту папку

### Шаг 3: Проверьте структуру файлов

Убедитесь, что структура выглядит так:

```
/config/custom_components/smm_9000/
├── __init__.py
├── manifest.json
├── config_flow.py
├── const.py
├── coordinator.py
├── switch.py
├── websocket_client.py
└── strings.json
```

### Шаг 4: Перезапустите Home Assistant

1. Перейдите в **Настройки** → **Система** → **Перезагрузка**
2. Или используйте кнопку перезагрузки в меню разработчика (Developer Tools)

**Важно**: После копирования файлов **обязательно** перезапустите Home Assistant!

## Способ 2: Установка через HACS (если репозиторий добавлен в HACS)

Если вы добавите этот репозиторий в HACS как custom repository:

1. Откройте **HACS** → **Интеграции**
2. Нажмите три точки (⋮) → **Custom repositories**
3. Добавьте репозиторий (URL репозитория)
4. Выберите категорию: **Integration**
5. Нажмите **Add**
6. Найдите **Grand Meyer SMM-9000** в HACS
7. Нажмите **Download**

## Настройка интеграции

После установки и перезагрузки:

1. Перейдите в **Настройки** → **Устройства и сервисы**
2. Нажмите **Добавить интеграцию** (кнопка в правом нижнем углу)
3. Найдите **"Grand Meyer SMM-9000"** в списке
4. Нажмите на интеграцию
5. Введите параметры:
   - **IP адрес устройства**: например `192.168.1.166`
   - **Пароль**: например `12345678`
6. Нажмите **Отправить**

### Если интеграция не появляется в списке

1. Проверьте, что файлы скопированы правильно
2. Проверьте, что перезагрузили Home Assistant
3. Проверьте логи Home Assistant:
   - **Настройки** → **Система** → **Журналы**
   - Ищите ошибки, связанные с `smm_9000`
4. Убедитесь, что папка называется именно `smm_9000` (без пробелов, с подчеркиванием)

## Проверка установки

После настройки:

1. Перейдите в **Настройки** → **Устройства и сервисы**
2. Найдите устройство **"SMM-9000"** в списке
3. Вы должны увидеть переключатели для каждой зоны устройства
4. Переключатели должны иметь названия типа **"SMM-9000 1 Лестница"** и т.д.

## Использование в автоматизациях

После установки вы можете использовать переключатели в автоматизациях:

1. Создайте новую автоматизацию
2. В действиях выберите **"Вызвать сервис"**
3. Найдите сервис `switch.turn_on` или `switch.turn_off`
4. Выберите нужную зону из списка сущностей

Или используйте в YAML:

```yaml
action:
  - service: switch.turn_on
    target:
      entity_id: switch.smm_9000_1_лестница
```

## Решение проблем

### Интеграция не появляется

- ✅ Убедитесь, что папка находится в правильном месте: `/config/custom_components/smm_9000/`
- ✅ Проверьте, что все файлы скопированы
- ✅ Перезапустите Home Assistant
- ✅ Проверьте логи на ошибки

### Ошибка подключения

- ✅ Проверьте IP адрес устройства
- ✅ Убедитесь, что устройство доступно в сети
- ✅ Проверьте пароль
- ✅ Проверьте, что порт WebSocket открыт (обычно 80)

### Зоны не обнаружены

- ✅ Проверьте логи Home Assistant на ошибки
- ✅ Убедитесь, что авторизация прошла успешно
- ✅ Проверьте, что устройство имеет настроенные зоны

### Просмотр логов

Для отладки включите подробное логирование в `configuration.yaml`:

```yaml
logger:
  default: info
  logs:
    custom_components.smm_9000: debug
```

После изменения перезапустите Home Assistant.

## Требования

- Home Assistant версии 2023.1.0 или новее
- Python 3.10+
- Доступ к устройству SMM-9000 по сети
- Знание IP адреса и пароля устройства

## Обновление интеграции

Для обновления:

1. Остановите интеграцию (удалите её из настроек, если нужно)
2. Замените файлы в `/config/custom_components/smm_9000/`
3. Перезапустите Home Assistant
4. Настройка сохранится автоматически

## Удаление интеграции

1. Перейдите в **Настройки** → **Устройства и сервисы**
2. Найдите интеграцию **SMM-9000**
3. Нажмите на три точки (⋮) → **Удалить**
4. (Опционально) Удалите папку `/config/custom_components/smm_9000/`
5. Перезапустите Home Assistant
