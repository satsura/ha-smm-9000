# Инструкция по установке интеграции в Home Assistant

## Способ 1: Через файловый менеджер Home Assistant (рекомендуется)

### Шаг 1: Откройте файловый менеджер

1. Войдите в админку Home Assistant
2. В боковом меню найдите **File editor** (Редактор файлов) или **Samba share** (если включен)
3. Если File editor не установлен:
   - Перейдите в **Настройки → Надстройки → Магазин надстроек**
   - Найдите и установите **File editor**

### Шаг 2: Создайте папку custom_components

1. В File editor откройте корневую директорию Home Assistant (обычно `/config`)
2. Если папки `custom_components` нет - создайте её
3. Откройте папку `custom_components`

### Шаг 3: Скопируйте интеграцию

**Вариант A: Через File editor (если поддерживает загрузку файлов)**

1. В File editor создайте новую папку `smm_9000` внутри `custom_components`
2. Скопируйте все файлы из `custom_components/smm_9000/` в эту папку:
   - `__init__.py`
   - `config_flow.py`
   - `const.py`
   - `coordinator.py`
   - `manifest.json`
   - `strings.json`
   - `switch.py`
   - `websocket_client.py`

**Вариант B: Через Samba/SSH (если доступен)**

1. Подключитесь к Home Assistant через Samba или SSH
2. Скопируйте папку `custom_components/smm_9000` в `/config/custom_components/`

**Вариант C: Через терминал (если Home Assistant на Linux)**

```bash
# Если у вас есть SSH доступ к серверу Home Assistant
scp -r custom_components/smm_9000 user@homeassistant:/config/custom_components/
```

### Шаг 4: Проверьте структуру

Убедитесь, что структура файлов правильная:

```
/config/
└── custom_components/
    └── smm_9000/
        ├── __init__.py
        ├── config_flow.py
        ├── const.py
        ├── coordinator.py
        ├── manifest.json
        ├── strings.json
        ├── switch.py
        └── websocket_client.py
```

### Шаг 5: Перезапустите Home Assistant

1. Перейдите в **Настройки → Система → Перезагрузка**
2. Нажмите **Перезагрузить Home Assistant**
3. Дождитесь полной перезагрузки (обычно 1-2 минуты)

### Шаг 6: Добавьте интеграцию

1. Перейдите в **Настройки → Устройства и сервисы**
2. Нажмите кнопку **Добавить интеграцию** (в правом нижнем углу)
3. В поиске введите: **Grand Meyer** или **SMM-9000**
4. Выберите **Grand Meyer SMM-9000**
5. Заполните форму:
   - **IP адрес или хост**: `192.168.1.166` (или ваш IP)
   - **Пароль**: `12345678` (или ваш пароль)
6. Нажмите **Отправить**

### Шаг 7: Проверьте установку

1. После успешной настройки вы увидите новое устройство **SMM-9000**
2. В разделе **Устройства и сервисы** должны появиться переключатели для каждой зоны
3. Проверьте, что переключатели работают (включение/выключение)

## Способ 2: Через HACS (если интеграция опубликована)

Если интеграция будет опубликована в HACS:

1. Установите HACS (если еще не установлен)
2. Перейдите в **HACS → Интеграции**
3. Найдите **Grand Meyer SMM-9000**
4. Нажмите **Установить**
5. Перезапустите Home Assistant
6. Добавьте интеграцию через **Настройки → Устройства и сервисы**

## Способ 3: Через Git (для разработки)

Если у вас есть доступ к терминалу Home Assistant:

```bash
# Войдите в контейнер/систему Home Assistant
cd /config
mkdir -p custom_components
cd custom_components

# Клонируйте репозиторий (если он в Git)
git clone <url_репозитория> smm_9000

# Или скопируйте файлы вручную
```

## Устранение проблем

### Интеграция не появляется в списке

1. **Проверьте структуру файлов** - все файлы должны быть в `custom_components/smm_9000/`
2. **Проверьте manifest.json** - файл должен быть валидным JSON
3. **Проверьте логи** - в **Настройки → Система → Логи** ищите ошибки
4. **Перезапустите Home Assistant** - иногда требуется полная перезагрузка

### Ошибка при добавлении интеграции

1. **Проверьте подключение к устройству**:
   ```bash
   # Проверьте доступность устройства
   ping 192.168.1.166
   ```

2. **Проверьте пароль** - убедитесь, что пароль правильный

3. **Проверьте логи** - в логах Home Assistant будут детали ошибки

### Переключатели не появляются

1. **Проверьте логи координатора** - возможно, устройство не отвечает
2. **Проверьте WebSocket соединение** - устройство должно быть доступно
3. **Проверьте авторизацию** - sess_id должен быть получен успешно

### Как посмотреть логи

1. Перейдите в **Настройки → Система → Логи**
2. В фильтре введите: `smm_9000`
3. Или включите debug логирование:
   - **Настройки → Устройства и сервисы → Интеграции**
   - Найдите интеграцию SMM-9000
   - Включите **Debug logging** (если доступно)

## Проверка работы

После установки проверьте:

1. ✅ Интеграция появляется в списке устройств
2. ✅ Создаются переключатели для каждой зоны
3. ✅ Переключатели отображают правильное состояние
4. ✅ Включение/выключение зон работает
5. ✅ Состояние обновляется автоматически

## Дополнительная информация

- **IP адрес устройства**: Обычно находится в настройках роутера или на самом устройстве
- **Пароль по умолчанию**: `12345678` (может быть изменен в настройках устройства)
- **Порт WebSocket**: Используется тот же порт, что и HTTP (обычно 80)

Если возникли проблемы:
1. Проверьте логи Home Assistant

3. Проверьте правильность IP адреса и пароля
4. Убедитесь, что все файлы скопированы правильно
